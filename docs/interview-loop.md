# Interview Feedback Loop

After an interview, capture each question, recall level (verbatim / near-verbatim / reconstructed), actual answer, weak points, relevant Career Facts, missing technical knowledge, and improved answer.

The improved answer may only use confirmed Career Facts. Interviewer intentions are hypotheses unless explicitly stated.

Link questions to an application and feed new factual clarifications into existing Career Facts, technical gaps into knowledge/, and reusable questions into interview/.
