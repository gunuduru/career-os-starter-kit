# Ingestion Guide

Accept natural conversation, speech transcription, and historical documents.

For each experience:
1. Identify the event, problem, constraints, user's own role, decisions, implementation, and results.
2. Check existing Career Facts for duplicates.
3. Split claims and assign evidence levels.
4. Preserve the original wording where available, labeled verbatim / near-verbatim / reconstructed.
5. Ask focused follow-ups about ownership, alternatives, before/after, scale, and measurable impact.
6. Keep unconfirmed values as open questions.
7. Save a canonical fact and source record. Do not write resume prose unless requested.

For historical resumes, treat every sentence as a claim, not automatically a verified fact. Distinguish planned work from shipped work. Do not infer production use from a PoC.

Evaluate a fact through the user's own target-role lenses, configured during setup.
