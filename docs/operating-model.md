# Operating Model

The latest `main` is authoritative, not conversation memory.

1. Read latest main and existing related records.
2. Create an issue or scoped task, then a short-lived topic branch.
3. When working concurrently, use a separate worktree.
4. Preserve meaningful source excerpts with provenance labels.
5. Commit small coherent changes and open a PR.
6. Review for duplicates, contradictions, unsupported claims, and confidentiality.
7. Merge when current knowledge is accurately represented, even if open questions remain.
8. Refresh main before the next task.

Use PR descriptions or commit bodies to record short "User request / provenance" notes. Never call a paraphrase verbatim.
